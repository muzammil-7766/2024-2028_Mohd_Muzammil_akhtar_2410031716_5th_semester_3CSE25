The **AI-ML Virtual Internship** provided an opportunity to learn the fundamentals of Artificial Intelligence and Machine Learning and understand how machine-learning concepts are applied in practical problems.

The internship focused on understanding the complete AI/ML workflow, including:

- Artificial Intelligence fundamentals
- Machine Learning concepts
- Data preprocessing
- Exploratory Data Analysis
- Feature preparation
- Machine Learning algorithms
- Model training

- Performance metrics
